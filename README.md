## 开发

`gradlew.bat build` 可独立构建，不需担架编译 JAR。可选桥使用字符串目标与插件检查，不解析缺席模组的类。
`DollCatalog` / `DollDefinition` 分离玩偶身份、皮肤和战斗参数；公共 `DollCombatAccess` 供额外玩偶接入。

`-PcombatTests` 才编译并启用 `src/testmod/java`，发布 JAR 排除所有测试类。
`runClient` / `runServer` 可传 `-PcombatRunDirectory=build/独立运行目录`，避免覆盖历史证据。
`-PcombatWithStretcher` 才复制兼容 fixture：本地需准备担架 JAR 于
`libs/compile/`，外部依赖 fixture 位于相邻担架项目的 `build/mod-fixture-occultism-full-1.224.4-20261019`。
这些本机测试依赖不会进入生产 JAR。

`-PcombatWithXiaoxiao` 加载本地萧萧联动夹具；萧萧原包位于用户提供的 `D:/AI/sources/DollSkinBlinkTool/output/mods/xiaoxiao-1.21.1-1.0.1-B-20261014-130221/jars`。它是可选运行联动，不打进生产 JAR。
