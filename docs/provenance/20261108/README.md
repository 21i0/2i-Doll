# Companion provenance retained on 2026-11-08

These records cover the four source-integrated companions Magua, Shuangshi,
Qiaotou and Canmeng. Each keeps its `1.21.1-1.0.0` registry identity and the
source author credit **2i学习**. Their original generated code LICENSE files
are copied byte-for-byte as `<mod_id>-SOURCE-LICENSE.txt`.

`source-provenance.json` retains the original source-manifest SHA256 and
relative source-file hashes. Local machine account paths, worlds, runtime
logs, standalone mod binaries and reference media are deliberately omitted.
The original imports are local verification material; these small records
allow checking the integrated code's provenance after duplicate build
archives are cleaned.

The MIT source license does not relicense owner-supplied skins or third-party
recordings. The four companions' existing pat-response OGGs match the shared
generated template; they are not advertised as new character recordings.
All existing asset exceptions, attribution and license boundaries remain in
[THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md).

This is a preservation record, not a new release or a grant of additional
asset rights. No user source project, public author material or original
LICENSE was removed or modified while making this record.
